## 检查项筛选

评分器先按场景为每一轮列出候选检查项，再去掉本轮不适用的项目。这里统计的是检查项次数，不是样本数。

| 阶段 | 数量 | 说明 |
|---|---:|---|
| 初始候选 | 540 | 根据样本场景和轮次列出的全部可能检查项 |
| 不适用并过滤 | 81 | 本轮没有对应天气调用、正常天气报告，或模板规定本轮不检查 |
| 进入评分 | 459 | 过滤后真正需要执行的检查项 |
| 成功产生结果 | 459 | 已得到 pass/fail 的检查项 |
| 因评分错误未产生结果 | 0 | 所属样本评分失败，因此整条样本未落分 |

计算关系：540 个候选 = 81 个过滤 + 459 个进入评分；459 个进入评分 = 459 个已产出结果 + 0 个未产出结果。

| 过滤原因 | 数量 | 含义 |
|---|---:|---|
| `no_new_weather_report` | 15 | 本轮没有新的正常天气报告，不重复检查城市名 |
| `no_weather_call` | 18 | 本轮没有天气工具调用，不检查工具参数 |
| `template_turn_not_applicable` | 48 | 按模板定义，本轮不需要此检查 |

> 被过滤的检查项不计通过或未通过。逐条筛选明细保留在 `scores.json` 的 `selection.filtered_details` 中，Markdown 不展开。
